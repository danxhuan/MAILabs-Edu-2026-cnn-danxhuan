> *Комментарии проверяющего*

1. 
В первой части лабораторной работы (файл Faces.ipynb) была реализована архитектура PetCNN, состоящая из трех сверточных блоков (Conv2d, ReLU, MaxPool2d) и полносвязного классификатора для предотвращения переобучения. Обученная с нуля модель показала отличные результаты в бинарной классификации (отличить кошку от собаки). Однако мультиклассовая классификация 35 пород оказалась для такой архитектуры сложной задачей, что обосновывает необходимость использования более глубоких предобученных сетей.
Были получены следующие результаты: 
Точность классификации пород: ~42% 
Top-3 Accuracy: ~66% 
Бинарная точность (Кошки / Собаки): ~89% 

2. 
Во второй части лабораторной работы необходимо было решить задачу классификации пород кошек и собак на основе датасета Oxford Pets (также доступен тут) с использованием Transfer Learning и визуализировать результаты работы сети для разных классов на разных изображениях с помощью алгоритма GradCam. Было проведено сравнение трех архитектур: VGG16, VGG19 и ResNet18. Веса моделей были заморожены, заменен только финальный классифицирующий слой. Экспериментальным путем установлено, что модель VGG19 показала наилучшую точность на данном датасете. С помощью алгоритма GradCAM были построены карты активации. Визуализация показала, что нейросеть при принятии решения фокусируется на ключевых признаках морды животного (глаза, форма ушей, нос). 

Результаты лучшей модели (VGG19):
Точность классификации пород: 88.91%
Top-3 Accuracy: 98.61%
Top-5 Accuracy: 99.48%
Бинарная точность: 94.25%

3. 
Третья часть предполагала проверку точности бинарной классификации кошек/собак и точность классификации изображений по породам с помощью фундаментальной предобученной сети CLIP и текстовых промптов. В ходе рабоыт модель CLIP тестировалась без дообучения на 100 случайных изображениях из Oxford Pets. Модель CLIP показала точность, сопоставимую с дообученной VGG19, вообще не обучаясь на данных изображениях.
Были получены следующие результаты: 
Точность классификации пород: ~100% 
Бинарная точность (Кошки / Собаки): ~87% 

4. 
Четвертая часть лабораторной работы была реализована через вариационный автоэнкодер для генерации изображений лиц домашних животных. Был реализован VAE с 128-мерным скрытым пространством. Модель обучалась в течение 20 эпох на датасете petfaces. Модель восстанавливает общие черты (положение головы, окрас), но теряет мелкие детали, изображение нечеткое, размытое. Это характерно для VAE из-за минимизации MSE-потерь. Модель способна создавать новые образы, отдаленно напоминающие морды животных.

В ходе работы были освоены три подхода к классификации: обучение с нуля, Transfer Learning и Zero-shot классификация (CLIP). Также были изучены принципы работы генеративных моделей (VAE) и методы интерпретации нейросетей (GradCAM). Наилучшую эффективность для прикладных задач показал метод Transfer Learning и использование фундаментальных моделей.

При выполнении работы использовался ИИ-ассистент для генерации и поиска ошибок в синтаксисе PyTorch, для настройки параметров GradCAM и для отладки логики сопоставления пород в CLIP.
